## Make changes you can explain

Configuration is more useful when it is understandable. Each Pegasus note should tell you what a change does, what it depends on, and how to undo it.

## Keep the surface small

Good defaults should remove friction, not hide decisions. Pegasus favours a few clear tools over a long list of features that need constant maintenance.

## Treat the machine as yours

Themes and configurations are suggestions, not a locked identity. Keep what helps, change what does not, and document the result for your future self.
